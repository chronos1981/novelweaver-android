# Screenshot provenance

The 30 PNG images are captures of the actual bundled NovelWeaver 2.1.3 editor
from `feature/create-dialogue-voice-2.1.3`, rendered in headless Chromium at
430 × 1000 CSS pixels. They use a demonstration project, synthetic revision
history, an example cover, and demonstration voice names. They do not show a
real manuscript, API key, connected AI server, Android file picker, or device
status bar. No live speech or AI request was made for these captures.

The two `android-auto-*-illustration.webp` files are AI-generated layout
illustrations previously created for this project. They are explicitly marked
as illustrations in the main README and are not evidence of testing in a car.

The README documentation change does not merge or alter the app feature branches.

The Bookcase, spine browsing, back-cover Details, and Manage covers captures
were updated from the bundled 2.3.0 UI with demonstration books and artwork.
